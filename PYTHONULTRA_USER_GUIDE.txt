PYTHONULTRA FOR CASIO fx-CG50
USER GUIDE / FEATURE REFERENCE
========================================

PROJECT
-------
PythonUltra is a community calculator Python environment based on PythonExtra
and MicroPython, using gint and JustUI on the Casio fx-CG50.

PythonUltra development is a co-collaboration between the
OffCamera-Civilman project and Brandon (@brandonendall), building on work by
Lephenixnoir, SlyVTT, MicroPython, gint, JustUI and Planete Casio contributors.

The build includes compatibility work for both older and newer fx-CG50 display
hardware.

PYTHONULTRA TERMINAL
--------------------
PythonUltra starts in a Linux-style terminal mode instead of immediately
forcing every line to be Python code.

Prompt example:
    PU:/$

Built-in commands:
    help man ls cd pwd mkdir touch rm rmdir mv cp cat echo clear chmod
    python zip unzip edit files modules info version
    alias unalias source history font theme rc

Get help:
    help
    help python
    man python
    python -h
    python --help

Most terminal commands also accept:
    command -h
    command --help

The manual pages show NAME, SYNOPSIS, options and examples.

PERMISSIONS / CHMOD
-------------------
The fx-CG50 storage filesystem does not expose real POSIX chmod mode bits.
PythonUltra therefore maintains its own persistent permission table and enforces
it across the PythonUltra terminal, Files application, editor and direct script
launcher.

The permission values follow normal Unix octal notation:
    read    = 4
    write   = 2
    execute = 1

Examples:
    chmod 444 file.txt
        Read-only.

    chmod 644 notes.txt
        Owner read/write; group/others read.

    chmod 755 hello.py
        Owner rwx; group/others read/execute.

    chmod 700 private.py
        Owner rwx only.

    chmod 777 tool.py
        Read/write/execute for all classes.

PythonUltra is a single-user calculator environment, so any enabled read/write
or execute bit permits that operation inside PythonUltra. The full nine-bit
mode is still stored and displayed to preserve normal Linux notation.

Permission records are stored persistently in:
    /.pythonultra_permissions

Files > F6 > Permissions provides common chmod modes and a Custom option.

Important Linux-style execution rule:
    python hello.py
requires READ permission because Python itself is interpreting the file.

Direct execution:
    chmod 755 hello.py
    ./hello.py
requires both READ and EXECUTE permission.

A 444 file can be opened/read in the editor, but PythonUltra will refuse to save
over it until write permission is restored, for example:
    chmod 644 file.txt


PYTHON COMMAND / REPL
---------------------
Enter interactive Python:
    python

To return to terminal mode:
    exit
or:
    exit()

Run a script:
    python hello.py

Run a script with arguments:
    python hello.py Brandon 42

Inside hello.py:
    import sys
    print(sys.argv)

The result contains:
    ['hello.py', 'Brandon', '42']

Run code directly:
    python -c "print(2+2)"

Python command help:
    python -h
    python --help

IMPORTANT ARGUMENT RULE:
    python hello.py -h
passes -h TO hello.py through sys.argv. It does not open PythonUltra's Python
help because the script name came first.

The clear command also works while in the Python REPL.


SHELL RC / ALIASES
------------------
PythonUltra uses a calculator-friendly shell configuration file:
    /.pythonultrarc

A default file is created automatically. It supports comments, startup cd,
aliases and persistent terminal font/theme preferences.

Example:
    # PythonUltra terminal configuration
    set theme=dark
    set font=normal
    cd /games
    alias ll='ls -l'
    alias py=python

List current aliases:
    alias

Create a session alias:
    alias ll='ls -l'

Remove it:
    unalias ll

Reload the RC file:
    source /.pythonultrarc
or:
    rc reload

Show the RC file:
    rc show

Edit it inside PythonUltra:
    rc edit

Aliases created only at the prompt last for the current session. Put them in
/.pythonultrarc to restore them after PythonUltra restarts.


COMMAND HISTORY
---------------
Current-session editing history:
    UP      older command
    DOWN    newer command

Terminal commands are also appended to the persistent history file:
    /.pythonultra_history

Display it:
    history

Show only the last 10 entries:
    history 10

Clear persistent history:
    history -c

SHIFT+UP/DOWN remains reserved for scrolling terminal output.


TERMINAL FONT SIZE
------------------
PythonUltra uses actual compiled fx-CG50 font resources rather than simulated
screen zoom.

Commands:
    font small
    font normal
    font large

The presets map to the compiled 9-, 13- and 19-pixel font resources.

Show the current choice:
    font

Persist the default in /.pythonultrarc:
    set font=small
or:
    set font=normal
or:
    set font=large


TERMINAL THEME
--------------
Commands:

Persist it in /.pythonultrarc:

F4 remains the quick shell theme toggle.

The Permissions menu includes common modes such as 444, 600, 644, 700, 755 and
777, plus a Custom chmod entry.

ZIP / UNZIP
-----------
PythonUltra includes a compact standard ZIP implementation backed by
MicroPython's DEFLATE engine.

Terminal:
    zip archive.zip source
    unzip archive.zip
    unzip archive.zip destination

Examples:
    zip mygame.zip mygame
    zip notes.zip notes.txt
    unzip mygame.zip mygame_copy

Files GUI:
1. Highlight a file or folder.
2. Press F6 (More).
3. Choose Compress to ZIP.
4. Enter the archive name.

To extract:
1. Highlight a .zip file.
2. Press EXE and choose Extract ZIP,
   or F6 > Extract ZIP.
3. Enter the destination folder.

Supported:
- stored ZIP entries
- DEFLATE-compressed entries
- files and folders
- CRC integrity checking
- safe extraction that rejects ../ path traversal

Not supported:
- encrypted ZIP files
- ZIP64
- multi-disk ZIP archives


PYTHONULTRA EDITOR
------------------
The integrated editor is based on the project's PyEditorRC concept, refactored
for PythonUltra and the fx-CG50.

Editor F-keys:
F1  Run (Python files)
F2  Save
F3  New
F4  Open
F5  Find
F6  Style

F6 > Syntax Theme provides:
- GitHub Dark
- GitHub Light
- Linux Terminal
- PythonUltra Dark
- PythonUltra Light

F6 > Font Size provides:
- small
- normal
- large

The editor font presets use the same compiled fx-CG50 9/13/19 font resources as
the terminal font system.

Navigation:
Arrow keys     move cursor
OPTN           toggle NORMAL / INSERT mode
EXE            create newline / enter insertion
DEL            backspace in INSERT mode
EXIT           leave editor (unsaved changes require confirmation)

Selection/clipboard:
SHIFT+8        begin VISUAL selection
OPTN           copy selection while in VISUAL mode
DEL            cut selection while in VISUAL mode
SHIFT+9        paste clipboard

Extra editor tools:
SHIFT+4        open curated PythonUltra module catalog and insert a name
SHIFT+DEL      symbol popup

The editor automatically indents after a line ending in ':'.
Highlighting distinguishes Python keywords, built-ins, numbers, strings,
comments, decorators, types, modules and operators.

The editor can edit ordinary text files as well as Python source.
PythonUltra rwx permissions are honored when opening, saving and running files.

NUMPY / MATRIX SUPPORT
----------------------
PythonUltra uses a calculator-sized NumPy compatibility package. The native
accelerator is private (_numpy_fast) so it no longer shadows the Python package.

Example:
    import numpy as np
    m = np.matrix([[1, 2], [3, 4]])
    print(m)
    print(m.T)
    print(m.I)

Aliases/helpers include:
    np.matrix np.mat np.asarray np.asmatrix np.dot np.cross
    np.norm np.normalize np.lerp np.matmul

Matrix functionality includes transpose, inverse, multiplication and matrix
power support in the compact implementation.

This is NOT full desktop NumPy. It is designed for fx-CG50 memory and CPU limits.


PYGAME
------
PythonUltra contains a compact calculator-focused Pygame compatibility layer.
It includes display/surfaces, Rect, drawing, key events, timing, fonts, image
loading, transforms and sprite/group helpers needed for lightweight games.

Calculator image guidance:
- keep loaded game images at or below 56x56 pixels
- large full-screen Surface allocations can exhaust contiguous MicroPython heap

No desktop SDL audio/network stack is included.


PY3D
----
PythonUltra includes a compact software 3D layer using native gint.dtriangle.
Current features include vectors, 4x4 matrices, transforms, perspective
projection, RGB565 shading, back-face culling, painter sorting, cube meshes and
a Renderer helper.

This is a calculator software renderer, not OpenGL/GPU acceleration.


CTYPES
------
PythonUltra includes a deliberately safe calculator-sized ctypes compatibility
layer with common scalar wrappers, managed byte buffers and allowlisted calls.
It does not expose unrestricted arbitrary-address memory access.


OS / FILESYSTEM
---------------
The calculator os module includes:
    getcwd chdir listdir mkdir remove unlink rename rmdir stat sep

Terminal cd changes the real working directory used by following terminal
commands and Python scripts.


DARK MODE / THEMES
------------------
The shell supports dark/light mode through F4 or the theme command.
The graphical Files application supports themed backgrounds.
The editor includes GitHub Dark/Light, Linux Terminal, PythonUltra Dark/Light,
and separate font-size selection.
The PythonUltra G3A app icon uses a black outer background.

HARDWARE TEST CHECKLIST
-----------------------
After installing a new G3A, verify on the physical calculator:

1. Terminal starts and shows PU:<path>$ prompt.
2. ls, pwd, mkdir, cd, touch, cat, mv, rm work.
3. `ls -l` displays rwx permissions.
4. `chmod 444 test.txt` makes it read-only inside PythonUltra.
5. Editor can read the 444 file but refuses to save over it.
6. `chmod 644 test.txt` restores write access.
7. `chmod 755 hello.py` then `./hello.py` directly runs the script.
8. python opens REPL; exit returns to terminal.
9. python test.py one two populates sys.argv correctly.
10. python -h and python --help show Python command manual.
11. clear clears terminal output.
12. UP/DOWN recalls current-session commands.
13. history displays /.pythonultra_history; history -c clears it.
14. Add an alias to /.pythonultrarc and verify it loads after restart.
15. Test font small, normal and large.
16. F1 opens dark/themed enhanced Files.
17. Create .txt and .py files and folders.
18. Rename and delete items.
19. Run/Edit selection for .py files.
20. Test Files > Permissions.
21. ZIP a file/folder and extract it.
22. F3 opens modal module/method catalog.
23. F4 toggles shell theme.
24. F5 opens editor.
25. Test all editor syntax themes and font sizes.
26. F6 displays build/collaboration info.
27. import numpy as np; np.matrix(...) works.
28. Test m.T and m.I.
29. Confirm the app icon outer background is black.

Automated build/tests do not replace physical fx-CG50 testing.


PROJECT NOTE
------------
PythonUltra intentionally prioritizes practical calculator programming,
2D/3D game development, usable filesystem tools and an onboard programming
workflow over strict feature-for-feature desktop Python compatibility.
